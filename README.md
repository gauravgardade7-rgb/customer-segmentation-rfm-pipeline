# Corporate Customer Segmentation Engine (RFM Pipeline)

## 📌 Project Overview
This project isolates, cleans, and profiles over 100,000 lines of unorganized transactional retail data. Using a programmatic Python pipeline, it dynamically maps out individual customer metrics and segments consumers into actionable marketing cohorts. 

## 🛠️ Tech Stack & Skills Used
- **Python**: Data engineering and transformation.
- **Pandas**: Structural data aggregation and dynamic string parsing.
- **OpenPyXL**: Automated spreadsheet formatting, layout formatting, and alignment controls.
- **Business Theory**: Recency, Frequency, and Monetary (RFM) behavioral analysis.

## 📊 Business Outcome
- Eliminated raw formatting noise and tokenization limits of default spreadsheet utilities.
- Successfully calculated consumer engagement behaviors into targeted marketing buckets.
- Auto-generated a polished executive marketing dashboard with live format metrics using single-click execution.
